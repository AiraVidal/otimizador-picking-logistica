# Otimizador de Picking Logístico 📦

Sistema desenvolvido em Python para otimização de rotas de coleta em armazéns, utilizando a biblioteca Pandas.

## 🚀 Objetivo
Reduzir o tempo de deslocamento de operadores de picking através da ordenação inteligente de itens baseada na localização física (Corredor e Prateleira).

## 🛠️ Tecnologias
- Python 3.x
- Pandas (Manipulação de dados)
- Git/GitHub (Versionamento)

## 📈 Diferencial
Este projeto une minha experiência prática no setor logístico (Continente/Randstad) com as competências técnicas que estou desenvolvendo no curso de Análise e Desenvolvimento de Sistemas (FMU).
